## `<audio>`

Sound for Eskiu: WAV and Ogg Vorbis files, a mixer and output through SDL3.

`<audio/wav>`, `<audio/ogg>` and `<audio/mixer>` are pure Eskiu; `<audio/device>` (and so
this module) links SDL3.


## `<audio/decode>`

Sound_load reads a sound file into a Sound: WAV (`<audio/wav>`) and Ogg Vorbis
(`<audio/ogg>`) on every platform, and on iOS and Android also what the system decodes
(MP3, AAC / M4A, FLAC; Opus on Android) through its own codecs (native/, built in by
eskiu-lang/ui apps). A file from the network is downloaded first (ui_fetch, `<fetch>`) and
loaded from disk.

```eskiu
Sound music = sound_load(path)?;
defer music.free();
```

sound_decode reads a WAV or Ogg Vorbis file already in memory, by its first bytes.

### sound_load

```eskiu
Result<Sound, string> sound_load(string path)
```

Reads and decodes the sound file at `path` (by its name: .wav is read by `<audio/wav>`,
.ogg by `<audio/ogg>`).

### sound_decode

```eskiu
Result<Sound, string> sound_decode(*uint8 d, uint64 len)
```

Decodes a WAV or Ogg Vorbis file held in memory (len bytes at d), known by its first
bytes; the samples are copied, so d can be freed after.


## `<audio/device>`

Sound output: SDL3 on macOS, Linux and Windows (a program that imports it
links SDL3; `<audio/wav>` and `<audio/mixer>` alone do not), a RemoteIO audio unit on iOS and
AAudio on Android (native/, built in by eskiu-lang/ui apps).

```eskiu
AudioDevice out = audio_open(48000)?;
defer out.close();
Mixer m = mixer_new(out.rate);
m.play(&music, AudioPlay{loop: true});
while (running) {
    out.pump(&m, 50);    // keeps 50 ms of mixed audio queued
    ...
}
```

### AudioOptions

```eskiu
struct AudioOptions {
    bool mix_with_others;
    bool ignore_silent;
    bool game;
    int buffer_ms = 500;
}
```

How the output shares the device. mix_with_others lets other apps' sound go on (iOS; on
Android media always mixes); ignore_silent plays with the iPhone's ringer switch on silent
(otherwise the switch mutes it); game marks the stream as a game's (Android's usage);
buffer_ms is the most that can be queued ahead (iOS and Android).

## `<audio/mixer>`

Mixes playing sounds and streams into a stereo float stream.

```eskiu
Mixer m = mixer_new(48000);
uint32 id = m.play(&jump, AudioPlay{volume: 0.8, pan: -0.3});
m.render(out, 512);      // 512 stereo frames, interleaved
```

Each voice reads its sound at its own rate and pitch (linear
interpolation), with volume, pan (-1 left to 1 right, equal power) and
looping. A mono sound plays on both sides; a sound with more than two
channels plays its first two. The sounds must live while they play.

A voice can also play an AudioSource, a stream that renders itself (a
sequencer, a decoder), and every voice plays on a bus: master, music,
sfx, or one added with Mixer_add_bus. Voices and buses fade over a time
in milliseconds, linearly in gain. Mixer_use_bgm, Mixer_use_me and
Mixer_use_bgs give voices the roles of a game's background music, a
fanfare that pauses that music while it plays, and background sound.

The output depends only on the calls made and the frame counts rendered,
never on wall time: rendering 4096 frames, or the same 4096 in blocks of
1 or 7, gives the same samples (Mixer_advance runs the timers on a video
clock instead).

### AudioSource

```eskiu
interface AudioSource {
    int64 render(*float out, int64 frames);
    bool done();
}
```

A stream the mixer plays: render writes up to frames stereo frames
(2 * frames floats, interleaved, at the mixer's rate) into out and
returns how many it wrote; done says no more will come. A source that
writes fewer frames and is not done plays silence for the rest.

### AUDIO_BUS_MASTER

```eskiu
const int AUDIO_BUS_MASTER = 0;
```

The buses every mixer has: master (everything ends there), music and sfx (both under
master). Mixer_add_bus adds more.

### AUDIO_BUS_MUSIC

```eskiu
const int AUDIO_BUS_MUSIC = 1;
```

The music bus, under master.

### AUDIO_BUS_SFX

```eskiu
const int AUDIO_BUS_SFX = 2;
```

The sound effects bus, under master.

### AudioPlay

```eskiu
struct AudioPlay {
    float volume = 1.0;
    float pan;
    float pitch = 1.0;
    bool loop;
    bool reverse;
    bool balance;
    int bus;
}
```

How Mixer_play plays a sound: volume (1 is the sound as recorded), pan (-1 left to 1
right, equal power), pitch (2 is an octave up and twice as fast), loop, reverse, and the
bus it plays on (master by default).

### Mixer

```eskiu
struct Mixer {
    int rate;
    float volume;
    List<_Voice> voices;
    uint32 next_id;
    List<_Bus> buses;
    bool mono;
    bool manual_clock;
    uint32 bgm;
    uint32 me;
    uint32 bgs;
}
```

Mixes the voices into stereo float frames at `rate` Hz. volume scales the whole mix;
mono mixes both channels to the same signal. Make one with mixer_new.

### mixer_new

```eskiu
Mixer mixer_new(int rate)
```

A mixer with no voices for output at rate frames per second, with the master, music and
sfx buses.

### Mixer_play

```eskiu
uint32 Mixer_play(*Mixer self, *Sound sound, AudioPlay opt)
```

Starts sound and returns its voice id. AudioPlay{} plays at full volume,
centered, at the sound's own pitch, once, on the master bus. pitch is
also the speed (a cry at 1.5 plays faster and higher); reverse plays the
sound from its end to its start.

### Mixer_play_source

```eskiu
uint32 Mixer_play_source(*Mixer self, AudioSource src, AudioPlay opt)
```

Starts a stream and returns its voice id. The source must live while it
plays; it renders at the mixer's rate, so pitch, loop and reverse do not
apply, and its pan is a stereo balance.

### Mixer_playing

Whether the voice `id` is still playing (paused counts as playing).

### Mixer_stop

Stops the voice `id` at once; an unknown id does nothing.

### Mixer_stop_all

### Mixer_set_volume

### Mixer_set_pan

```eskiu
void Mixer_set_pan(*Mixer self, uint32 id, float pan)
```

Sets the voice's pan, from -1 (left) to 1 (right).

### Mixer_set_pitch


Sets the voice's pitch (1 is the sound's own rate, 2 an octave up); a stream's pitch

### Mixer_current

### Mixer_position

### Mixer_pause

### Mixer_resume

### Mixer_set_mono


Mono output: each frame plays the average of its two channels on both sides.

### Mixer_use_bgm

```eskiu
void Mixer_use_bgm(*Mixer self, uint32 id, int fade_ms)
```

Makes the voice the background music. The music before it fades out and stops while this
one fades in, over fade_ms (with 0 the old one stops and this one plays at once); while a
fanfare plays, the new music waits paused. Given the voice that is already the music, it
only fades it back to full over fade_ms.

### Mixer_stop_bgm

```eskiu
void Mixer_stop_bgm(*Mixer self, int fade_ms)
```

Fades the background music out over fade_ms and stops it (at once for 0).

### Mixer_use_me

```eskiu
void Mixer_use_me(*Mixer self, uint32 id)
```

Makes the voice the fanfare (ME): the background music pauses where it is and resumes on
the frame after the fanfare ends or stops. A new fanfare stops the one before.

### Mixer_use_bgs

```eskiu
void Mixer_use_bgs(*Mixer self, uint32 id)
```

Makes the voice the background sound (BGS), stopping the one before.

### Mixer_stop_bgs

```eskiu
void Mixer_stop_bgs(*Mixer self)
```

Stops the background sound, if one plays.

### Mixer_bgm

```eskiu
uint32 Mixer_bgm(*Mixer self)
```

The voice in each role, or 0 when none plays.

### Mixer_me

```eskiu
uint32 Mixer_me(*Mixer self)
```

The fanfare voice, or 0 when none plays.

### Mixer_bgs

```eskiu
uint32 Mixer_bgs(*Mixer self)
```

The background sound voice, or 0 when none plays.

### Mixer_set_manual_clock

```eskiu
void Mixer_set_manual_clock(*Mixer self, bool manual)
```

Fades and the fanfare's end are timers. By default they run on the
frames rendered, sample by sample. With the manual clock they run only
in Mixer_advance, and a render mixes at the gains the last advance left:
a video recorder calls m.advance(dt) and then m.render(out, frames) for
each video frame.

### Mixer_advance

```eskiu
void Mixer_advance(*Mixer self, double dt)
```

With the manual clock, runs the timers dt seconds of the caller's clock forward in one
step (a video frame). Without it the rendered frames are the clock and this does nothing.

### Mixer_render

```eskiu
void Mixer_render(*Mixer self, *float out, int frames)
```

Writes frames stereo frames (2 * frames floats) of the mix into out and
advances every voice; voices that end are removed. Voices add in the
order they started.

### Mixer_free

```eskiu
void Mixer_free(*Mixer self)
```

Stops every voice and frees the mixer's lists; the sounds it played are the caller's.


## `<audio/ogg>`

Ogg Vorbis files to float samples, decoded whole or a block at a time as they
play.

```eskiu
Sound jump = ogg_load("jump.ogg")?;                       // the whole file
defer jump.free();
OggStream town = ogg_stream("town.ogg", 48000, true)?;    // decoded as it plays
defer town.free();
m.use_bgm(m.play_source(&town, AudioPlay{bus: AUDIO_BUS_MUSIC}), 500);
```

The decoder is written in Eskiu, ported from stb_vorbis by Sean Barrett and the
stb_vorbis contributors (public domain or MIT, at your choice), so it needs no library and
runs wherever Eskiu does. It reads Vorbis I with floor 1, which is what every encoder
writes; floor 0 is refused. A file's LOOPSTART and LOOPLENGTH (or LOOPEND) comments, in
frames, are its loop points. Seeking is exact to the frame and decodes at most two packets.

### OggVorbis

```eskiu
struct OggVorbis {
    int channels;
    int rate;
    uint64 frames;
    uint64 loop_start;
    uint64 loop_end;
}
```

An open Ogg Vorbis file: channels, rate, length in frames and loop points (loop_end 0
when the file has none), and the decoder's place in it. Read frames with read, move with
seek, and free it when done. Make one with ogg_open or ogg_open_memory.

### OggStream

```eskiu
struct OggStream {
    OggVorbis ogg;
    int rate;
    bool loop;
}
```

An Ogg Vorbis file as an AudioSource: decoded a block at a time as the mixer asks,
resampled to the mixer's rate (linear interpolation, as a voice plays a Sound) and, when

file for a file without loop points). A mono file plays on both sides; a file with more
than two channels plays its first two. Make one with ogg_stream or ogg_stream_from.

## `<audio/wav>`

WAV files to and from float samples.

Decoding reads RIFF WAVE (and WAVE_FORMAT_EXTENSIBLE) with 8, 16, 24 and
32-bit integer PCM, 32 and 64-bit float, IMA ADPCM and Microsoft ADPCM.
Every format becomes interleaved float samples between -1 and 1:

```eskiu
Sound s = wav_load("jump.wav")?;
defer s.free();
printf("%llu frames, %d channels at %d Hz\n", s.frames, s.channels, s.rate);
```

wav_save writes 16-bit PCM or 32-bit float.

### Sound

```eskiu
struct Sound {
    *float data;
    uint64 frames;
    int channels;
    int rate;
    uint64 loop_start;
    uint64 loop_end;
}
```

frames samples per channel, interleaved: data holds frames * channels
floats. A looping voice plays it from loop_start to loop_end (frames, loop_end
exclusive) after its first pass to loop_end; with loop_end 0 it loops the whole sound.

### Sound_free

```eskiu
void Sound_free(*Sound self)
```

Frees the samples; the Sound is empty after it.

### sound_new

```eskiu
Sound sound_new(uint64 frames, int channels, int rate)
```

A sound of frames silent frames.

### wav_load

```eskiu
Result<Sound, string> wav_load(string path)
```

Reads and decodes the WAV file at path.

### wav_decode

```eskiu
Result<Sound, string> wav_decode(*uint8 d, uint64 len)
```

Decodes a WAV file held in memory (len bytes at d); the samples are copied, so d can be
freed after.

### wav_save

```eskiu
Result<int, string> wav_save(string path, *Sound s, int bits)
```

Writes the sound as a WAV file of 16-bit PCM (bits 16) or 32-bit float
(bits 32).
